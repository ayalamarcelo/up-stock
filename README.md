## Correr proyecto
Para poner en marcha el backend, sigue estos pasos:

1. `cd backend`
2. `dotnet restore`
3. `dotnet run`
4. `dotnet ef database update --framework net9.0` 
5. Accede a la API en: [http://localhost:5102/swagger](http://localhost:5102/swagger)

> [!NOTE]
> Solo si el paso 3 no les funciona, eligen la versión de .NET que tienen.
